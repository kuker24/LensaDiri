## Anti-Patterns Verdict

**LLM assessment:** Does **not** read as generic AI SaaS. Design2 monochrome portal + cinematic media color split is earned and distinctive. Residual risks: mono-label eyebrow density, section-factory film-strip cadence, frosted nav blur, and entry-path product archaeology—not purple gradients or icon card grids.

**Deterministic scan:** CLI TSX scan on 14 key files → **0 findings** (exit 0). Static rendered homepage HTML → **1** advisory `numbered-section-markers` (01–03 steps). Playwright browser inject → **5** signals (overused Inter, gradient-text×2, thin-border+shadow on hidden mobile menu, theater-slop-phrase). Most browser signals are **false positives** against this intentional Design2 stack (Inter is brand font; scrim gradient is not gradient text; mobile menu shadow only when open; no “theater” copy in DOM). Real residual: intentional numbered sequence scaffolding + possible over-reliance on Inter as display+UI.

**Visual overlays:** No user-visible Impeccable overlay (no live-inject config / puppeteer URL engine). Browser evidence via Playwright evaluate only.

## Overall Impression

The entrance is memorable, premium, and on-voice: private reflection without clinical or quiz kitsch. The single biggest opportunity is **closing the trust→action gap and collapsing the `/start` decision tree** so the quiet gallery promise survives the first commitment click.

## What's Working

1. **Committed Design2 monochrome + media color split** — charcoal CTAs, frost hairlines, film-strip marketing, spectrum marks without neon.
2. **Structure over cards** — hairline rows and numbered process beats identical feature grids; scientific humility appears early.
3. **Compose-path craft** — numbered lens/depth steps, live estimate, experimental ack, recovery panel feel more mature than many marketing middles.

## Priority Issues

### [P0] `/start` dual primary paths (modular + Quick + Standard)

- **Why it matters:** Hero sells one calm “Mulai eksplorasi”; first-timers hit three peer primaries and product history (legacy vs modular).
- **Fix:** One default recommended path; demote legacy to tertiary disclosure.
- **Suggested command:** `/impeccable shape start-entry` then `/impeccable distill start`

### [P1] Homepage peak–end without re-commitment CTA

- **Why it matters:** Trust panel is the last major beat; no return invitation to begin after privacy reassurance.
- **Fix:** Final quiet void strip: one line + charcoal Mulai + ghost Metode.
- **Suggested command:** `/impeccable layout homepage-close`

### [P1] Jargon & English chrome without local meaning

- **Why it matters:** Evidence Tier A/B, Private · modular, Deterministik, English lens names raise prestige and opacity for Indonesian first-timers.
- **Fix:** Indonesian-first labels + one-line tier meaning near first badge; English in tooltip/Metode.
- **Suggested command:** `/impeccable clarify homepage-language`

### [P2] Primary charcoal under-signals on pure black

- **Why it matters:** Elegance vs “I should press this”; secondary sits visually close to primary.
- **Fix:** Stronger frost border / lens-strong rest; keep secondary quieter; no violet.
- **Suggested command:** `/impeccable polish primary-cta`

### [P2] Film-strip + mono-label section factory

- **Why it matters:** Four bands with the same recipe + repeated mono-labels flatten emotional arc.
- **Fix:** Differentiate one strip; cut ~30% mono-labels; let h2 carry voice.
- **Suggested command:** `/impeccable quieter marketing-strips`
