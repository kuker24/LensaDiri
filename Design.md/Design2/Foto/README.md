# Design2 Foto prompts

Still prompts for Grok (or image gen). Same worlds as Video pack — posters, strips, panel, OG, mobile.

## Alur

1. Buka `prompt1.txt` … `prompt7.txt`
2. Copy blok di bawah `===== COPY PROMPT DI BAWAH INI =====`
3. Set ukuran di tool sesuai SPEC di header file
4. Drop ke `assets/` dengan nama di header
5. Rename UUID via `assets/ORDER.txt` jika perlu
6. Compress → `EXPORT.md`
7. Beri path ke agent untuk wire

## File

| File | Fungsi |
|------|--------|
| `prompt1.txt`–`prompt7.txt` | Paste-ready |
| `PROMPT.md` | Index |
| `EXPORT.md` | sizes + compress |
| `assets/` | Drop hasil |
